## PRACTICE
Complete these in your Day 19 folder against a small HTML page, and push them to GitHub. They warm you up for the Week-2 project.
1. Select an `<h1>` and change its text with textContent, then add a CSS class to it with classList.toggle.
2. Given an array of three Ethiopian city names, create an `<li>` for each with createElement and append them to a `<ul>`.
3. Add a click listener to a button that logs event.target, then wrap the button in a div with its own listener and observe bubbling.
4. Build a list of items each with a delete button, and remove any item using a single delegated listener on the parent.
5. Add a form with one text input; on submit, preventDefault, read input.value, append it to a list, and clear the field.
